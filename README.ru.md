# Экономия действий

[English](./README.md) · Русский

Модуль Foundry VTT 14 для D&D5e: счётчики основного действия, бонусного действия,
свободного действия, реакции и концентрации в шапке листа персонажа.

Проверен на Foundry 14.367, D&D5e 5.3.3, Midi-QOL 14.0.12.

## Проверка без установки

Если ставить модуль пока не хочется, есть автономная версия одним макросом:
[tools/standalone-macro.js](./tools/standalone-macro.js). Создать макрос типа Script,
вставить содержимое, запустить — включится, запустить ещё раз — выключится.

Умеет всё то же самое, но работает только у того, кто его запустил, и до перезагрузки
страницы. Настройки — константами в начале макроса, а не в интерфейсе Foundry.
Флаги и ключи эффектов те же, что у модуля, поэтому при переходе на модуль ничего
не потеряется. Перед включением модуля макрос надо выключить, иначе ресурсы будут
списываться дважды.

## Установка

В Foundry: **Настройки → Модули → Установить модуль**, в поле «Манифест» вставить

```
https://github.com/Kon4ka/action-economy/releases/latest/download/module.json
```

Вручную: распаковать архив релиза в `Data/modules/action-economy` и включить модуль в мире.

## Как читать виджет

Каждая строка — ресурс: значок и точки. Точек столько, сколько ресурса всего, чёрные —
потраченные.

| Значок | Ресурс | Кто списывает |
| --- | --- | --- |
| Зелёный круг | Основное действие | автоматика при использовании Activity с активацией «Действие» |
| Рыжий треугольник | Бонусное действие | автоматика, активация «Бонусное действие» |
| Синяя капля | Свободное действие | только вручную |
| Бирюзовая стрелка | Реакция | автоматика, активация «Реакция» |
| Розовое кольцо | Концентрация | система D&D5e |

Активация `special` (переключатели вроде «режим стеклянной пушки») не стоит ничего.

Если навести курсор на занятую точку концентрации, подсказка покажет, что именно персонаж
держит. На свободной будет написано, что слот свободен. Ручной режим на это не влияет:
концентрацию всегда ведёт система.

## Показ виджета

**По умолчанию виджета нет ни у кого.** Включается в меню листа под тремя точками, двумя
независимыми выключателями — достаточно любого из них:

- **«Показывать у меня»** — лично для этого пользователя, сразу на всех листах персонажей.
  То же самое есть в личных настройках модуля.
- **«Показывать у этого персонажа»** — для всех, но только на этом листе. Доступно владельцу
  листа и мастеру, хранится во флаге персонажа.

Повторный выбор того же пункта выключает показ обратно.

## Управление

- **Клик по свободной точке** — потратить единицу ресурса.
- **Клик по чёрной точке** — вернуть единицу.
- **Клик по значку** — восстановить весь ресурс.
- **Клик по точке концентрации** — снять эту концентрацию (спросит подтверждение).
- **Правый клик по виджету** — окно «Экономия действий»: жёсткое количество каждого ресурса
  и предел концентрации для этого персонажа. То же самое есть в меню листа под тремя точками.

Ресурсы восстанавливаются сами в начале хода персонажа и по окончании боя.

## Как повысить количество ресурсов

Активным эффектом. Ключи:

```
flags.action-economy.max.action      Режим «Прибавить», значение 1
flags.action-economy.max.bonus
flags.action-economy.max.reaction
flags.action-economy.max.free
system.attributes.concentration.limit   штатное поле системы
```

Несколько концентраций D&D5e поддерживает сама: при новой концентрации система сравнивает
число активных с `system.attributes.concentration.limit` и снимает старую, только когда
лимит исчерпан. Поэтому при лимите 2 персонаж честно держит две, и считать вручную не надо.
Постоянное значение задаётся в том же окне «Экономия действий», временное — эффектом.

Работают режимы «Прибавить», «Умножить», «Повысить», «Понизить» и «Переопределить»,
учитывается приоритет. Отключённые и подавленные эффекты не считаются.

Готовые особенности с такими эффектами создаёт макрос
[tools/create-effects.js](./tools/create-effects.js): запустить один раз от мастера,
затем перетаскивать особенности на листы.

## Настройки

- **Ручной режим** — модуль ничего не списывает сам.
- **Если ресурса не осталось** — предупредить и спросить подтверждение (по умолчанию),
  только уведомление, либо ничего не делать. В последнем случае обработчик не регистрируется.
- **Вести учёт вне боя** — списывать ли ресурсы, когда боя нет.
- **Показывать основное действие / бонусное / свободное / реакцию / концентрацию** —
  мировые настройки мастера: какие ресурсы вообще видны на листах.
- **Показывать виджет у меня** — личный выключатель, по умолчанию выключен (см. «Показ виджета»).

## Границы

- Работает только на листах персонажей (`character`). НПС не трогает.
- «Дополнительная атака» тратит действие на каждое использование активности атаки —
  лишнее списание возвращается кликом по точке.
- Свободные действия автоматика не распознаёт: в D&D5e нет такого типа активации.
- Виджету нужна шапка штатного листа D&D5e. На сторонних листах модуль молчит и просто
  ничего не рисует.

## Совместимость

Модуль ничего не патчит: шесть хуков, восемь настроек в своём пространстве имён и один узел
в шапке листа. Пишет только в `flags.action-economy` на актёре и в
`system.attributes.concentration.limit`, когда это поле меняешь сам. Ни обёрток прототипов,
ни libWrapper, ни правок `CONFIG`, ни моделей данных, ни сокетов, ни своих типов документов —
поэтому обычных конфликтов «двое обернули один метод» у него быть не может.

- [tools/probe-activity-hooks.js](./tools/probe-activity-hooks.js) — какие хуки и в каком

Логика проверяется без Foundry: `node tests/smoke-test.cjs`.

## Релизы

Каждый коммит в основную ветку выпускает релиз: workflow поднимает патч-версию, дописывает
CHANGELOG из сообщений коммитов, собирает архив и публикует его с инструкцией по установке.
Чтобы коммит не выпускал релиз, добавь в его сообщение `[skip release]`. Если нужен
нормальный текст заметок вместо списка коммитов — заполни секцию «Unreleased» в CHANGELOG,
она уйдёт в релиз и очистится.

План, проверенные факты API и открытые вопросы — в [PLAN.md](./PLAN.md).
